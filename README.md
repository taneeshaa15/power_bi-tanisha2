# E-Commerce Sales Dashboard 📊

**Author**: Tanisha Garg  
**Tool Used**: Microsoft Power BI  
**Project Type**: Business Intelligence Dashboard

---

## 📌 Overview

This project presents a detailed and interactive **E-Commerce Sales Dashboard** created using **Power BI**. It allows users to analyze key performance indicators (KPIs) across various dimensions such as time, product category, geography, customer segments, and payment modes.

---

## 📈 Key Metrics

- 🔢 **Total Sales Amount**: 438K
- 💰 **Total Profit**: 37K
- 📦 **Total Quantity Sold**: 5615
- 📊 **Average Order Value (AOV)**: 121K

---

## 📊 Visual Elements

- **Profit by Month**: Monthly analysis of profit trends from January to December
- **Quantity by Category**:
  - Clothing: 63%
  - Electronics: 21%
  - Furniture: 17%
- **Profit by Sub-Category**:
  - Top contributors: Printers, Bookcases, Saree, Accessories, Tables
- **Sales Amount by State**: Maharashtra, Madhya Pradesh, Uttar Pradesh, Delhi
- **Sales Amount by Customer**: Havanrah, Madhavi, Madan Mohan, Shiva
- **Quantity by Payment Mode**:
  - COD: 44%
  - UPI: 21%
  - Debit Card: 13%
  - Credit Card: 12%

---

## 🔧 Features & Filters

- **Quarter Filter**: Qtr 1 to Qtr 4
- **State Filter**: Multi-state selection for regional analysis
- **Interactive Charts**: All visuals update dynamically based on filters
- **Responsive Design**: Visually appealing layout using Power BI themes and formatting

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**: For building interactive dashboards and reports
- **Excel/CSV** : As the underlying data source

---

## 🔍 Insights Gained

- Maharashtra is the top-performing state in terms of revenue.
- Clothing dominates the sales quantity, followed by electronics.
- COD remains the most popular payment method.
- Printers generate the highest profit among all sub-categories.
- July shows a dip in profit, which could be an area for strategic review.
